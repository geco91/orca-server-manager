First steps in Orca

  1. Choose Add project to clone a repository from its URL, open a folder on the server, or create a new project in /workspaces.
  2. Choose New workspace to start a task in your project. For an existing GitHub issue, open Tasks → GitHub → Issues and choose Start beside the issue to set up a linked workspace.
  3. Choose an agent in the workspace’s agent picker and give it a first task. Try “How do I run this project’s tests?”
  4. After an edit, open Source Control to review the changes. Run the relevant tests in the workspace terminal before committing.
